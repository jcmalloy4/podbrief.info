#479 – Dave Plummer: Programming, Autism, and Old-School Microsoft Stories

Key Takeaways

  • Dave Plummer, a former Microsoft engineer, created Windows Task Manager and ported 3D Pinball.
  • Microsoft's early success was driven by highly talented individuals and Bill Gates' vision for a computer in every home.
  • Early software development at Microsoft involved significant time (80%) spent on debugging and fixing issues across multiple architectures.
  • Task Manager was developed as a personal project, prioritizing robustness, reliability, and a small file size (87KB).
  • Windows activation, implemented for Windows XP, significantly impacted Microsoft's revenue despite user frustration.
  • Dave Plummer shares insights on autism and ADHD, noting the advantages of intense focus in programming.
  • Current programming language benchmarks show Zig, Rust, and C/C++ leading in prime number calculation performance.
  • AI is rapidly evolving programming towards higher-level abstraction, with developers managing components rather than writing lines of code.

Deep Dive

  • The guest secured a Microsoft summer internship by cold-emailing employees after reading a biography of Bill Gates.
  • He developed HyperCache, a file system cache for the Amiga, primarily in C with low-level I/O functions in 68,000 assembly.
  • HyperCache was sold to fund his education and career pursuits after being distributed via Usenet and Amiga forums.

  • The guest's work involved porting the Windows 95 shell to NT, leading to its ranking as a highly impactful operating system.
  • Daily tasks in the Windows 95 era included triaging bugs from overnight system crashes via serial cables.
  • Approximately 80% of development work focused on bug fixes and porting code, rather than new feature creation.
  • Porting the Windows 95 user interface to NT required a significant Unicode conversion and detailed line-by-line code examination.

  • Software development demanded deep understanding, requiring debugging in low-level assembly across Intel, MIPS, Alpha, and PowerPC architectures.
  • Roughly 80% of professional time was dedicated to debugging and fixing existing issues, not new feature creation.
  • A persistent Task Manager bug, showing CPU usage over 100%, was ultimately traced to a kernel accounting error.
  • Assertions were critical tools for stopping code execution to pinpoint and address bugs efficiently.

  • The guest ported 3D Pinball: Space Cadet to Windows NT, rewriting assembly code into C to demonstrate graphics capabilities.
  • A physics bug during porting led to faster-than-intended gameplay in subsequent versions of 3D Pinball.
  • Implemented Windows activation for Windows XP, a process that significantly boosted revenue but caused user frustration.
  • The phone activation process for Windows XP was particularly disliked by users.

  • Microsoft acquired the guest's shareware zip file support after a cold-call, leading to its integration into Windows.
  • Internal refinement of Windows zip support at Microsoft involved removing encryption due to then-existing export restrictions.
  • The guest contributed to early 1996 prototypes of Windows Media Center, which featured a distance viewing UI for satellite content.
  • The history of Zip originates from the BBS era, with Phil Cass's PKZIP for MS-DOS as a notable precursor.

  • The guest is building an AI for the 1980 Atari game Tempest, using Lua to extract data for Python reinforcement learning.
  • The Tempest AI, employing a dueling deep Q-network, has achieved level 36, exceeding most human players but not the maximum 96.
  • A past company, Software Online, faced legal issues with the Washington State Attorney General over upgrade notifications and default physical media shipments.
  • The company's practices prompted users for actions or included physical media by default for online purchases.

  • The guest's favorite Windows versions are Windows 2000 Server for stability and Windows XP for its consumer impact and longevity.
  • Slot machine outcomes are determined by a random number generator before visual animations occur.
  • He is restoring vintage computers, including a PDP-11, maximizing its memory to four megabytes.
  • Modifications to the BSD kernel were made to support the PDP-11's unique features, including blinking lights.

  • Individuals on the autism spectrum face challenges interpreting unsaid social cues and often take language literally.
  • The guest employs "emotional post-processing" to review social interactions, analyze errors, and refine future responses.
  • While not always detecting social cues, autistic individuals are capable of empathy once they comprehend another's experience.
  • Directness and specificity are crucial when communicating with individuals on the autism spectrum.

  • Autistic traits like single-minded focus, curiosity, and detail orientation contribute to programming success.
  • Current projects include training an AI for Tempest and restoring a PDP-11 computer with an RA82 drive.
  • The "GitHub Primes" project benchmarks prime number algorithms on a machine with 1 terabyte of RAM.
  • Languages like Zig, Rust, and C/C++ currently show leading performance in finding primes up to 100 million.
